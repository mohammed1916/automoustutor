# AI Studio app

View app in AI Studio: https://ai.studio/apps/drive/13iB8yPmXKpqeZFQeHrDECJWZTJIzMwLS

## Run Locally

**Prerequisites:**  Node.js - v24.13.0


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
